# SimpleDisguiseSystem
Disguise and Blend into hostile area by wearing faction specific armor. Simple and Easy.

Simple Disguise System - SDS is a mod that enables player to disguise as hostile faction and infiltrate the enemy base.
The system is designed to be as simple as possible.
Without any complicated settings and configurations.
The main function of the mod is to evaluate what player is wearing and check for specific keywords.
If a condition is met, the mod will add the relevant faction to player faction list. when the condition becomes false [Or some specific event happens], the mod will remove the faction from the player.
